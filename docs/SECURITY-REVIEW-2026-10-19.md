## Delivered in ShieldPress 1.5.0

- Optional `block_udrpc` checks parsed GET/POST/request parameter presence at `plugins_loaded` priority -100, before Updraft's `wp_loaded` command handler. No administrator exemption; empty and array values are blocked. Raw JSON is not inspected by this feature because the tested Updraft listener consumes PHP POST parameters. The switch is off by default and explicitly warns about remote-management/migration compatibility.
- `map_meta_cap` enforces the installation lock for network super admins. A real multisite capability test reproduces the old `user_has_cap` bypass and verifies the fix. This is not a network-wide RPC integration test.
- Reviewed offline version warnings supplement remote metadata. Results are deduplicated by component/CVE and exposed only to administrators or appropriately scoped paired tokens. Explicit token scopes are respected; defaults remain for legacy tokens without scope metadata.
- Paid plans, licensing routes/UI, paid addon loading and license-authenticated metrics push have been removed. The upgrade cleans legacy license credentials/caches and obsolete push schedules. App pairing and built-in features remain.

No new core path-resolution patch is claimed: update WordPress to fix CVE-2026-87902. No exhaustive third-party CVE protection is claimed.
